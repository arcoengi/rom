GITHUB PAGES — ЦИФРОВАЯ ВИЗИТКА

ЗАГРУЖАЙ ВСЁ СОДЕРЖИМОЕ ЭТОЙ ПАПКИ В КОРЕНЬ РЕПОЗИТОРИЯ:

index.html
style.css
script.js
assets/
  logo.png
  regina.jpg

ВАЖНО:
Не загружай только index.html отдельно.
Папка assets должна лежать рядом с index.html.

GitHub:
Settings → Pages → Deploy from a branch → main → /(root) → Save

После публикации открой ссылку GitHub Pages.

Если картинки снова не показываются:
1. Открой репозиторий.
2. Нажми папку assets.
3. Убедись, что там есть logo.png и regina.jpg.
4. Названия должны быть именно в нижнем регистре.
